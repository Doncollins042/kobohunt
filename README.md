# KoboHunt

> Playable prototype of a campus cash-drop charity hunt: live tilted map, swipe-to-collect, wallet, winners board, donation portal and an adjustable revenue model.

## Run

Single self-contained file — open `index.html` in any browser, or deploy the folder as-is to Netlify / Vercel / GitHub Pages.
