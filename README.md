# KoboHunt

> Campus cash-drop charity hunt with a live tilted map, swipe-to-collect, in-app wallet, winners board, donation portal and an adjustable revenue model.

## Features
- Live tilted map showing active cash drops
- Swipe-to-collect interaction
- Wallet and winners leaderboard
- Donation portal for charity partners
- Adjustable revenue model for operators

## Tech
HTML, CSS, JavaScript

## Run

Single self-contained build. Open `index.html` in any browser, or deploy the folder as-is to Netlify, Vercel or GitHub Pages.
